# Spec 18: Continuous integration

**Status:** 🟢 Implemented
**Author:** renatoctti
**Date:** 2026-11-02
**Scope:** a GitHub Actions workflow that runs the quality gate on every push and pull request
**Depends on:** 11
**Delivery:** autonomous (after its dependencies)

---

## Summary

The project already has a gate that the author runs by hand: ruff check, ruff format check and
pytest. This spec runs the same three commands on GitHub for every push to main and every pull
request, on the two newest Python versions the project supports, so a regression or a missing file
in a clean checkout shows up without anyone remembering to look.

## Context

The tests need no API key and no network: the model, the embeddings and the clock are all faked or
fixed in the tests. The workflow therefore uses no secret. It also runs on Linux while the author
works on Windows, which checks paths, line endings and the accent in the name of the manual.

---

## Allowed files

**Production:** .github/workflows/ci.yml (new)

**Tests:** tests/test_ci.py (new)

**Docs:** README.md (a status badge and a line in the section on tests), PROJECT_MAP.md

**Do not touch:** the source code (a failure on Linux is a finding, fixed in its own change).

## Functional requirements

| ID | Requirement | Priority | Acceptance |
|---|---|---|---|
| ✅ RF-01 | The workflow runs on push to main and on pull requests | Must | Static check of the triggers |
| ✅ RF-02 | It installs the project with the dev extras and runs ruff check, ruff format --check and pytest | Must | Static check of the commands |
| ✅ RF-03 | It runs on Python 3.11 and 3.12 | Must | Static check of the matrix |
| ✅ RF-04 | It has read-only permissions and uses no secret | Must | Static check |
| ✅ RF-05 | The README shows the status of the workflow | Should | README test |

## Non-functional requirements

- Third-party actions are limited to the official checkout and setup-python actions.

## Out of scope

- Deploying anything, publishing a package, running the live evaluation (it needs a key and costs money).

## Test checklist

- [x] ✅ Triggers, commands, matrix and permissions of the workflow
- [x] ✅ The first run on GitHub is green (checked after the push)
