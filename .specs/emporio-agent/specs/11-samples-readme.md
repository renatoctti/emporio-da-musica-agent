## Summary

Produces the deliverables the challenge grades besides the code: three to five conversation
transcripts (at least one non-trivial) and a README with run instructions, justified decisions,
known limitations and the AI-assistant usage.

## Context

The transcripts must be real runs, so they are generated with `emporio replay` from the scripts
kept in the repository. A live LLM key is required for this spec.

## Contracts

No code contracts. File layout:

```
samples/
  README.md
  scripts/01-catalog.txt ... 05-out-of-scope-es.txt
  01-catalog.md ... 05-out-of-scope-es.md
```

Each script line is one customer message; lines starting with `#` document the reference date and
the command used (`emporio replay samples/scripts/01-catalog.txt --today 2026-03-25 -o samples/01-catalog.md`).

## Edge cases

| ID | Scenario | Trigger | Expected behavior |
|---|---|---|---|
| 🟡 EC-01 | A replay produces a poor answer | transcript shows a wrong claim | Fix the cause (prompt or tool) in a separate commit and regenerate; never edit a transcript by hand |
| 🟡 EC-02 | Private data in transcripts | e-mails and phone numbers | Only the fictional customers from the provided CSVs appear |
| 🟡 EC-03 | Missing key at generation time | no `LLM_API_KEY` | Stop and ask the author for the key; do not fabricate transcripts |
