# Sample conversations

Five conversations with Melô, generated by the real agent (model `anthropic/claude-haiku-5.5`
through OpenRouter) from the customer lines in `scripts/`. The transcripts were produced by
`emporio replay` and are not edited by hand. Each tool call the agent made is shown as a quote,
followed by the first 300 characters of what the tool returned, so the data and policy lookups are
visible.

| File | Reference date | What it shows |
|---|---|---|
| [01-catalog.md](01-catalog.md) | 2026-03-25 | Product search with a price filter and availability; a follow-up answered from the previous result |
| [02-price-installments.md](02-price-installments.md) | 2026-03-25 | A product with an active promotion: original and promotional price, installment limit computed by the code (5x, not 10x), PIX discount that does not stack with promotions |
| [03-order-status.md](03-order-status.md) | 2026-03-25 | Identity check (a wrong e-mail is refused without revealing anything), order status and tracking, an estimated delivery that already passed, and a handoff ticket |
| [04-return.md](04-return.md) | 2026-02-19 | **Non-trivial case.** A regret return: verification, deadline rules applied by code, the manual item cited, customer confirmation and a ticket with a protocol and a response deadline counted in store opening hours |
| [05-out-of-scope-es.md](05-out-of-scope-es.md) | 2026-03-25 | A customer writing in Spanish asks for accessories (the store sells only instruments, no invented partner stores), then for the Saturday hours |

## About the reference dates

The sample data ends in March 2026, so each run fixes "today" with `--today`. Sample 04 uses
2026-02-19 because every delivered order in the data was received more than 7 days before
2026-03-25, and the point of that sample is a return that is still inside the regret window.

## Regenerating

```bash
# a fresh database keeps the ticket protocol at 0001 and avoids reusing an older ticket
set EMPORIO_DB_PATH=%TEMP%\samples.db        # Windows cmd; use `export` on Linux and macOS
emporio replay samples/scripts/04-return.txt --today 2026-02-19 -o samples/04-return.md
```

Use the matching `.txt` script. Each script starts with comments that give its reference date.
Answers vary a little from run to run (the model is not deterministic), so a regenerated
transcript will not be word for word identical.
